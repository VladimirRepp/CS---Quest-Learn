# Характиристики проекта:
- функционал: регистрация, вход, просмотр всех, калькулятор с историей операции 
- архитектуру: MVC
- роли: админ - редактор пользователей; пользователь - калькулятор
- хранилище: txt файл

# ТЗ на практику: 
- доделать функционал "Регистрация"
- сделать окно для админа 
- сделать окно для пользователя 

# Функционал админа: 
- таблица со всеми пользователями 
- редактирование данных всех пользователей (+ сохранение в файл) 

# Функционал пользователя: 
- калькулятор (любое количество действий, можно только +  -  *  /) 
- сохранять историю операций 
- просмотр истории операций
